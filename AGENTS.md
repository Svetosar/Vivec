# Vivec — правила проекта

Школьная газета с мини-CMS. Rust + axum + SQLite, публичная часть — SSR, админка — Vue 3.
Сдача **30.11.2026**. Бюджет **2–3 часа в день**.

**Перед любой задачей прочитать `TODO.md`.**
Полные правила, стек и чек-листы — в скилле `vivec` (`.opencode/skills/vivec/SKILL.md`).

## Жёсткие правила

1. **Проверять, не выдумывать.** API и версии — через context7 или официальные доки. Не проверил — так и сказать.
2. **Опасное — спрашивать:** `push --force`, переписывание истории, миграции с `DROP`, `rm -rf`, правка `Caddyfile`/3x-ui/VPN, удаление веток, новая зависимость.
3. **`main` — только проверенный код.** Любая работа — в ветке `feature/…`, `fix/…`, `chore/…`. Мерж только `--no-ff` после чек-листа и явного «да».
4. **`TODO.md` обновляется всегда** — до и после задачи.
5. **Правило 30 строк:** не давать код, который пользователь не сможет пересказать. Сначала объяснение, потом код.
6. **Скоуп заморожен 26.11.** Идеи — в `docs/backlog.md`.
7. **Не говорить «работает», не запустив.** `cargo check` → запуск → `curl`.
8. **Память ведётся письменно.** В конце каждой сессии — запись в `docs/journal.md`, ловушки — в `docs/gotchas.md` со статусом `проверено`/`гипотеза`/`решение`. Повторилось дважды — поднять в скилл `vivec`.

## Стек (не менять без разрешения)

axum 0.8 · tokio · SQLite + sqlx (runtime-запросы) · minijinja + `include_str!` · pulldown-cmark + ammonia · argon2 · Vue 3 + Vite + md-editor-v3 · podman rootless + Quadlet + Caddy.

Запрещено: ORM, generics, макросы, `unsafe`, `chrono` в типах, SPA на публичной части, Docker, сборка на сервере, PrimeVue/Pinia/TypeScript.
